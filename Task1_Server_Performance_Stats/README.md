# Server Performance Stats

Скрипт `server-stats.sh` выводит основные показатели Linux-сервера. [Страница задания на roadmap.sh](https://roadmap.sh/projects/server-stats)

## Запуск

Откройте терминал в папке со скриптом и выполните:

```bash
bash server-stats.sh
```

Понадобятся Linux, Bash и стандартные системные утилиты. Права администратора не требуются.

## Что показывает отчёт

- Общую загрузку процессора за одну секунду.
- Объём занятой и доступной оперативной памяти в МиБ и процентах.
- Занятое и доступное место на каждой файловой системе в блоках по 1 КиБ и процентах.
- Пять процессов с наибольшей средней загрузкой CPU за время работы процесса.
- Пять процессов с наибольшим объёмом резидентной памяти (RSS).

Синтаксис проверен командой `bash -n server-stats.sh`. Скрипт успешно запущен на Ubuntu 24.04 в WSL.
